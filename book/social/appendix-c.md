## LinkedIn

Appendix C of Learning Rust by Building FastMCP is out: icons and the server card.

FastMCP stores icons on the server and on each component. The Rust appendix checks the source prefix and the size spelling, then writes one JSON object with `name`, `websiteUrl`, and the icons that passed. A `file://` URL is dropped. Nothing is fetched, and the image is not put on `tools/list`.

[personal note]

Written for a reader who is new to Rust. The theme is an enum, so the only strings that come out are `light` and `dark`.
